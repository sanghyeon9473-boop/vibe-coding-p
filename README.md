# 💻 Sanghyeon An — Solo Developer Portfolio

1인 개발자(Solo Developer) 안상현의 모던 반응형 웹 포트폴리오 웹사이트입니다.

HTML, CSS, JavaScript로 분리 설계되어 가볍고 빠르며, 데스크톱부터 모바일 스마트폰까지 모든 기기에서 최적화된 사용자 경험을 제공합니다.

---

## ✨ 주요 기능 및 특징

- **모던 비주얼 디자인**: 부드러운 라벤더 배경과 바이올렛/옐로우 포인트 컬러를 활용한 감각적인 UI
- **완벽한 모바일 반응형**: 스마트폰 화면에서도 잘림 없는 1열 자동 정렬 및 애니메이션 햄버거 메뉴 지원
- **인터랙티브 미디어 쇼케이스**: 재생/일시정지 및 실시간 타임코드 연동 영상 플레이어 인터랙션
- **개발 역량 & 프로세스 소개**:
  - `Architecture` (시스템 아키텍처 및 기획)
  - `Development` (풀스택 웹/앱 개발)
  - `Testing & QA` (검증 및 최적화)
  - `Deployment` (클라우드 인프라 및 CI/CD 배포)
- **문의하기 팝업 모달 & 폼**: 원클릭 이메일 문의 및 메시지 전송 시뮬레이션

---

## 📁 파일 구조

```bash
├── index.html        # 웹페이지 구조 및 콘텐츠 (HTML5)
├── style.css         # 모던 반응형 디자인 및 스타일시트 (CSS3)
├── script.js         # 메뉴, 미디어 플레이어, 모달 등 인터랙션 (Vanilla JS)
├── images/           # 고화질 이미지 에셋
└── assets/           # 리소스 에셋
```

---

## 🚀 로컬 실행 방법

별도의 복잡한 설치 없이 브라우저에서 `index.html` 파일을 더블 클릭하여 바로 열 수 있습니다.

또는 로컬 서버를 통해 실행할 수도 있습니다:

```bash
# Python 내장 웹 서버 실행 (선택사항)
python3 -m http.server 8080
```
브라우저에서 `http://localhost:8080`으로 접속하여 확인하세요.
